YESPS Pro

YESPS Pro 是一个全球地震可视化模拟终端。
它尝试用更直观、更沉浸的方式，让人重新感受那些曾真实发生过的大地震。

当 P 波扩散、S 波抵达、红色能量场在地图上蔓延时，屏幕中的每一次震动，都对应着现实世界里曾存在过的城市、灯火与人。

项目基于真实历史地震数据构建，采用单文件架构与高性能渲染设计，希望在技术模拟之外，也保留对灾难本身最基本的敬畏。

功能特性
	•	实时 P 波 / S 波传播模拟
	•	历史地震事件动态回放
	•	全球地图可视化
	•	原生风格沉浸式 UI
	•	高性能实时渲染
	•	单文件运行，无需后端

内置历史地震
	•	2008 汶川地震
	•	2011 东日本大地震
	•	2023 土耳其地震
	•	1960 智利大地震
	•	1976 唐山地震

运行方式

直接使用浏览器打开：

YESPS Pro.html

无需安装环境或额外依赖。
